AI-DRIVEN CLAIMS TRIAGE - EASY WINDOWS VERSION
================================================

QUICKEST METHOD
1. Extract the complete ZIP file.
2. Open the extracted claims_triage_easy_run folder.
3. Double-click START_APPLICATION.bat.
4. Keep the black window open.
5. The application should open automatically in your browser.

If the browser does not open, manually visit:
http://localhost:8000

IMPORTANT
- Do not run the BAT file while it is still inside the ZIP preview.
- Extract the ZIP first.
- Do not move START_APPLICATION.bat outside the project folder.
- Python 3 must be installed.
- No pip install, API key, external API, or internet connection is required after Python is installed.

IF WINDOWS BLOCKS THE BAT FILE
1. Right-click START_APPLICATION.bat.
2. Select Properties.
3. If an Unblock checkbox appears, select it and click Apply.
4. Double-click the file again.

ALTERNATE METHOD
1. Right-click START_APPLICATION.ps1.
2. Select Run with PowerShell.

COMMAND PROMPT METHOD
1. Open the project folder.
2. Click the File Explorer address bar.
3. Type cmd and press Enter.
4. Run one of these commands:

   py -m app.server

   or

   python -m app.server

5. Open http://localhost:8000

STOPPING THE APP
Return to the black terminal window and press Ctrl+C.
