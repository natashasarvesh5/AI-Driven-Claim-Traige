# Five-minute stakeholder demo

1. **Context (30 sec):** Manual triage delays assignment. This prototype proves the workflow locally, with no external API dependency.
2. **Dashboard (60 sec):** Show claims sorted into priorities and specialized queues. Filter to Critical.
3. **New claim (90 sec):** Submit the prefilled multi-vehicle injury example. Explain three separate scores, reason codes, confidence, and recommended route.
4. **Change the scenario (45 sec):** Remove the injury and reduce the amount. Re-run to demonstrate dynamic reprioritization.
5. **Bulk CSV (45 sec):** Upload the included sample and show local batch results.
6. **Governance (30 sec):** Show the audit log and clarify that this is recommendation-only with human accountability.
7. **Roadmap (30 sec):** Present the future API-enabled architecture and production evaluation plan.

Closing line: "We have validated the concept and user journey without external dependencies. The next step is to calibrate it on approved, de-identified historical data and integrate it in shadow mode."
